Audio Settings

Help
Integrated loudness after normalization (EBU R128). -18 suits background theme music; lower = quieter.
Duration of the fade-in effect at the beginning
Longer themes (e.g. full songs from YouTube) are cut to this length and faded out. 0 = keep the full song.
Duration of the fade-out effect at the end
Leave empty to use Jellyfin's own FFmpeg (Dashboard → Playback → Transcoding), or give a full path like '/usr/bin/ffmpeg'

Storage

Optional. A folder on the server's own disk, e.g. /var/lib/jellyfin/themesongs. The real files are kept there and each series folder only gets a theme.mp3 symlink, so playing themes doesn't wake the media disks. The link only works inside Jellyfin (other machines that see the media folder see a broken link).
Series no provider had a theme for are asked again only after this many days.

Theme Song Providers

Sources are asked from top to bottom (lowest priority number first); if one has nothing, the next is tried. Nothing is built in: add the sources you want and fill in their URL.
Needed only by providers that return YouTube links (ThemerrDB). Empty = yt-dlp from PATH.




"Look up again" asks the providers now for every series without a theme (normally only every "Retry Not Found" days); existing themes are not touched. Force re-downloads every series' theme, except the ones you uploaded or deleted yourself.
